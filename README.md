# Pokémon Explorer

A responsive Pokédex built with Next.js and the public [PokéAPI](https://pokeapi.co/). Browse the first 151 Pokémon, search by name, and open a detail page for types, abilities, base stats, height, weight, and moves.

## Run locally

1. Install Node.js (18 or newer).
2. In this folder, install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

The app fetches data and artwork from PokéAPI, so an internet connection is needed while using it. No API key is required.
